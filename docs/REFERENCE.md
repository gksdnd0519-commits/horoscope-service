# 레퍼런스 분석

## 수집 개요

| 항목 | 내용 |
| --- | --- |
| 대상 | 운세의신(unsin.co.kr) 무료 **별자리운세** `/unse/free/conste/form` |
| 방법 | Firecrawl `scrape` API + `actions`(별자리 카드 클릭 → 결과보기 클릭) — `references/crawler/crawl_conste.py` |
| 범위 | 12개 별자리 전체 |
| 저장 | `references/raw/{별자리}.json`, `.md` — **저작권 보호를 위해 git 제외, 로컬 분석용** |

> 참고: 결과 페이지(`/result`)는 폼 POST로만 열린다. 단순 POST(curl)로는 서버가 값을 인식하지 못해 빈 결과가 나와서, 브라우저 렌더링 기반인 Firecrawl actions로 실제 클릭을 재현했다.

## 수집 결과 요약

레퍼런스는 이름은 "오늘의 운세"지만 **날짜와 상관없이 별자리별 고정 텍스트**를 보여준다.

| 섹션 | 내용 | 평균 분량(자) |
| --- | --- | --- |
| 성격 | 수호성, 성향, 장단점 | 약 500 |
| 직업 | 적성, 추천 직업군, 같은 별자리 유명인 | 약 390 |
| 행운요소 | 수·요일·날·꽃·보석·색·장소·방향·나라·취미 (10개 항목) | 약 200 |
| 결혼 | 연애·결혼관, 주의점 | 약 280 |
| 건강 | 취약 부위, 주의할 나이 | 약 125 |

## 레퍼런스에서 가져올 점 / 개선할 점

| 가져올 점 | 개선할 점 (우리 서비스) |
| --- | --- |
| 별자리 하나에 성격·직업·연애·건강·행운요소를 묶은 프로필 구성 | 날짜마다 바뀌는 **진짜 오늘의 운세**(항목별 점수 + 메시지) |
| 행운요소처럼 가볍게 훑어보는 정보 | 10개 행운요소 → 핵심 4개(색·숫자·요일·보석)로 축약 |
| 국내 기준 별자리 기간 | 생년월일 입력 시 **자동 판별** (레퍼런스는 직접 선택만 가능) |
| | 긴 문단 → 2~3문장 카드형, 모바일 우선 |
| | 궁합 기능 및 결과 링크 공유 추가 |
| | 광고·PHP 오류 메시지 노출 없는 깔끔한 화면 (레퍼런스는 단순 POST 시 PHP Notice 노출) |

## 콘텐츠 원칙

- 서비스에 들어가는 모든 문구는 **자체 작성**하며 레퍼런스 원문을 복사하지 않는다.
- 레퍼런스는 섹션 구성, 분량, 기간 기준을 정하는 데만 사용한다.
